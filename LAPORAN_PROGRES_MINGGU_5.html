IV. PANDUAN PEMAKAIAN DAN CARA AKSES (BAGI PUBLIK)

1. Prasyarat Sistem (Prerequisites)

Sebelum menjalankan aplikasi, pastikan komputer Anda telah terinstal:

  • PHP >= 8.1
  • Composer
  • Node.js & NPM
  • MySQL / MariaDB

2. Langkah-langkah Instalasi Lokal (Clone & Setup)

  1. Clone Repositori & Masuk ke Branch: 
    git clone https://github.com/BrilianVico/TUBES-PDPL-2470246-2472043.git
cd TUBES-PDPL-2470246-2472043
git checkout MINGGU-5---BrilianVico
  2. Install Dependensi PHP & Node.js: 
    composer install
npm install
  3. Konfigurasi Environment:

    Salin file .env.example menjadi .env dan sesuaikan konfigurasi database Anda.

    cp .env.example .env
  4. Generate App Key & Jalankan Migrasi Database: 
    php artisan key:generate
php artisan migrate --seed
  5. Jalankan Build Assets: 
    npm run build
  6. Jalankan Server Lokal: 
    php artisan serve

    Aplikasi dapat diakses di browser melalui tautan http://127.0.0.1:8000.
